Add a crop: wizard

Interactive mock. Opened from Home → Your crops → Add a crop or Farm → + Add crop.

Steps

  1. Soil type (BSWM series). The farm's series is pre-selected. "Not sure" is allowed.
  2. Soil texture, suggested from the series. The farmer can change it.
  3. Sensor (required): type a sticker code, or pick a kit already on the farm that has no plot.
  4. Wait for the first reading from that sensor. Matches appear on their own when it arrives (live).
  5. Crop matches based on this plot's sensor reading + soil + weather.
  6. Done: the crop is selected on Home with stats from its own sensor.

Behavior

  • The plot (soil + sensor) is saved at step 3, so the farmer can leave while waiting and come back later.
  • A kit already on another crop cannot be picked (one sensor = one plot).
  • Crops already growing on the farm are not listed in matches.
